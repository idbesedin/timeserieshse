# ДЗ 1. Анализ временного ряда продаж

В [ноутбуке](hw1/hw1_analysis.ipynb) разбираем продажи товара `84692` (*BOX OF 24 COCKTAIL PARASOLS*) с 1 декабря 2010 по 9 декабря 2011 года. Считаем количество проданных единиц без отмен, возвратов и строк с нулевой ценой. На лекции разбирали товар `85123A`.

## Как повторить анализ

1. Скачайте `Online Retail.xlsx` из [репозитория UCI](https://archive.ics.uci.edu/dataset/352/online%2Bretail) и поместите в корень проекта рядом с этим README. Набор данных *Online Retail* (2015) опубликовал Daqing Chen. Лицензия [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
2. Из корня проекта создайте окружение Python 3.11 и запустите JupyterLab.

   ```bash
   python3.11 -m venv .venv
   source .venv/bin/activate
   python -m pip install -r hw1/requirements.txt
   python -m jupyterlab
   ```

3. Откройте `hw1/hw1_analysis.ipynb`, выберите ядро Python 3 из созданного окружения и запустите все ячейки по порядку.

Функции анализа находятся в [hw1/ts_tools.py](hw1/ts_tools.py).

## Результаты

| Частота | Позиций в ряду | Продано, шт. |
| --- | ---: | ---: |
| Дни (Пн–Пт и Вс) | 321 | 7 908 |
| Полные недели (Пн–Вс) | 52 | 7 548 |
| Полные месяцы | 12 | 7 689 |

Недельные и месячные суммы считаем за полные календарные периоды, поэтому они отличаются от дневной суммы.

- **Качество данных.** В выгрузке нет транзакций по субботам. Среди остальных дней в 16 дат нет записей по всему магазину, их отмечаем как NaN. Для 46 наблюдаемых дней без продаж товара ставим 0. В недельном ряду есть одна неделя, за которую в выгрузке нет транзакций. Для расчётов на регулярной сетке дневные пропуски заполняем средним по соседним наблюдениям того же дня недели. Для пропущенной недели используем линейную интерполяцию. IQR отметил 14 дней. Дневной максимум в 426 шт. 27 апреля оставляем в ряду, в него входит заказ на 400 шт.
- **Уровень и разброс.** У дневных продаж коэффициент вариации равен 1,44, у недельных 0,57. Линейного тренда за этот период не обнаружили.
- **Сезонность.** По воскресеньям в среднем продавалось 6,8 шт. против 26–34 шт. по будням (Краскел–Уоллис, p ≈ 7,52 × 10⁻⁸ для различий между днями недели). Пик периодограммы соответствует периоду около 6 позиций дневного ряда, или одной календарной неделе. Сила недельной компоненты STL на шкале `ln(1+y)` составляет 0,264. В остатках есть автокорреляция. Для проверки годовой сезонности данных недостаточно.
- **Стационарность.** На уровне 5% ADF отвергает единичный корень, а KPSS не отвергает стационарность заполненных дневного и недельного рядов. При 12 месячных точках результат зависит от спецификации теста. Разности рассчитали для сравнения. В итоговой предобработке обошлись без дифференцирования. В дневном прогнозе нужно учитывать эффект дня недели.
