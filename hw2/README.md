# ДЗ 2. Прогнозирование продаж

В [ноутбуке](hw2_forecasting.ipynb) сравниваем прогнозы продаж товара `84692` (*BOX OF 24 COCKTAIL PARASOLS*) из Online Retail. Берём ряды из [ДЗ 1](../hw1/hw1_analysis.ipynb): 321 день без суббот, 52 полные недели и 12 полных месяцев. Единица измерения — число проданных наборов.

## Эксперимент

Наивная модель повторяет последнюю неделю для дневного ряда и последнее значение для недельного и месячного. Простое экспоненциальное сглаживание (SES) оценивает уровень продаж. CatBoost предсказывает следующий шаг по лагам и скользящему среднему, а для дней учитывает ещё и день недели. На несколько шагов вперёд он использует свои предыдущие прогнозы.

Границу обучения сдвигаем по одной позиции. Для дней берём 24 даты старта, для недель — 8, для месяцев — 4. Модели сравниваем по ошибке ровно на указанном шаге. Пропуски в истории заполняем только по прошлым значениям. В тесте сравниваем прогноз с исходными продажами.

## Результаты

Для каждого шага выбираем модель с минимальной MAE. MAE показывает средний размер ошибки в штуках за период, WAPE — сумму абсолютных ошибок в процентах от продаж на проверенных датах.

| Частота | Шаг | Лучшая модель по MAE | MAE, шт. | WAPE |
| --- | ---: | --- | ---: | ---: |
| День | 1 | CatBoost | 19,15 | 64,46% |
| День | 7 | SES | 22,96 | 79,30% |
| День | 31 | Сезонная наивная | 21,76 | 78,90% |
| День | 61 | CatBoost | 17,10 | 75,05% |
| Неделя | 1 | CatBoost | 51,28 | 35,03% |
| Неделя | 4 | SES | 63,98 | 37,55% |
| Неделя | 8 | SES | 44,43 | 27,34% |
| Месяц | 1 | SES | 121,88 | 20,32% |
| Месяц | 2 | Наивная | 107,00 | 16,65% |

Для следующей недели CatBoost дал в среднем на 21,93 шт. меньшую ошибку, чем SES. На четырёх неделях разрыв между ними меньше одной единицы. В дневном ряду ни одна модель не выиграла на всех горизонтах. Ошибка на длинном горизонте местами ниже, чем на коротком: при одинаковых стартах на разных шагах проверяются разные даты. На месячных данных лидер меняется между первым и вторым шагами. Для каждого месячного горизонта есть только четыре прогноза.

[Все 27 сочетаний модели, частоты и горизонта](metrics.csv) содержат MAE, RMSE, WAPE и число наблюдений. В [таблице прогнозов](forecasts.csv) сохранены факты и прогнозы для каждого шага каждого окна. Графики в ноутбуке показывают траектории из последнего окна и ошибки по всем окнам.

## Как повторить

1. Поместите `Online Retail.xlsx` из [репозитория UCI](https://archive.ics.uci.edu/dataset/352/online%2Bretail) в корень проекта, как для ДЗ 1.
2. Из корня проекта установите зависимости в окружение Python 3.11.

   ```bash
   python3.11 -m venv .venv  # если окружения ещё нет
   source .venv/bin/activate
   python -m pip install -r hw2/requirements.txt
   ```

3. Откройте [ноутбук](hw2_forecasting.ipynb), выберите Python из `.venv` и выполните все ячейки сверху вниз. Ноутбук заново построит ряды и запишет обе таблицы в папку `hw2`.

Модели, метрики и графики собраны в [ts_tools.py](ts_tools.py). Подготовка транзакций использует [код ДЗ 1](../hw1/ts_tools.py).
